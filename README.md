# model-selection-hyperparameter-tuning
This project demonstrates how to choose the best machine learning model for a classification task and improve its performance using hyperparameter tuning. A real dataset (IRIS.csv) is used to train, tune, and evaluate multiple algorithms.

What This Project Includes :-

Loading and preprocessing the dataset
Splitting data into train & test sets
Feature scaling for required models

Training and evaluating:-

Logistic Regression
Support Vector Machine (SVM)
Random Forest
MLP Neural Network
Tuning the MLP classifier using GridSearchCV
Comparing all models using:
Accuracy
Precision
Recall
F1-score
